**一句话人格**：等宽字 + 纯灰阶 + 全局克制——文字几乎只有一种颜色深浅的差别，唯一的红被宪法级地保留给"真的不可逆"。这不是配色方案，是把"只报总量不报风险"翻译成了视觉语言。

## 2. Color Palette（dark）

`.dark` 同构 28 变量（见 variables.css）：background 0.145 / card 0.205 / foreground 0.985；**注意** dark 的 `sidebar-primary` 是蓝（0.488 0.243 264°）——shadcn 预设残留，SwiftUI 侧应改回灰阶以守宪法（记入 §12 偏差）。

## 3. Typography

- Family：**JetBrains Mono Variable**（本地 @fontsource，无 CDN；`html { @apply font-mono }` 全站等宽）；heading = mono 同族
- Weights: 400/500/600/700（组件内 font-medium/font-semibold 为主）
- Scale（实测使用档）：text-xs(12) 辅助/mono 路径 · text-sm(14) 全局正文密度 · text-base(16) 卡标 · text-xl(20) 页标；数字一律 `tabular-nums`（2 处起步，SwiftUI 侧升为强制）
- 行高：正文 `leading-relaxed`；描述段落 ≥1.5

## 4. Spacing

Anchor: 4px（Tailwind 默认刻度）。实测高频：gap-2/3（8/12，列表行内）· p-4（16，卡片/详情）· p-6（24，页边距）· space-y-5（详情小节）。

## 5. Border Radii

Anchor `--radius: 0.625rem (10px)`；scale = sm 6 / md 8 / **lg 10（清单表容器、对话框）** / xl 14 / 2xl 18。语义：容器 lg、控件 md、徽章/头像 full。

## 6. Shadows

体系极轻：`shadow-2xl` 仅 1 处（详情浮层投影，作为"层级即深度"的唯一手段）；其余层级靠 border + bg 色差。来源 shadcn/tailwind.css 包内默认，项目未自定义 → 建议沉淀 `elevation.overlay = 2xl` 单 token。

## 7. Motion

`tw-animate-css`（覆层进出场默认）+ 状态过渡 150ms（Badge 更新，edge 规格）。宪法：无装饰性动效；`prefers-reduced-motion` 在 SwiftUI 侧对应 `accessibilityReduceMotion` 直接门控。

## 8. Breakpoints

Tailwind 默认 sm640/md768/lg1024/xl1280。但产品为桌面 App：**声明式最小窗口 960px**（Sheet520+详情360 并存），断点只在 <1100px 时收缩详情为 overlay。SwiftUI 用 `.frame(minWidth: 960)` 落实。

## 9. Z-Index

组件库内部（dropdown/overlay=50）+ 项目唯一自定义 `z-[70]`（详情浮于 diff Sheet 上）。建议固化为 `z.detail-overlay=70`。

## 10. Icon Set

lucide-react，16px（h-4 w-4）描边图标，语义位固定：FolderOpen=Skill / Server=MCP / Bot=Agent 行为 / ShieldCheck=授权 / History=变动 / RotateCcw=恢复。纯展示图标一律 `text-muted-foreground`。

## 11. Component Patterns（实测）

| 模式 | 规格 |
| --- | --- |
| 动作按钮 | **variant="outline" 为默认动作色（12 处）；primary 每屏 ≤1**——"动作克制"是本设计语言的组件级宪法 |
| 状态徽章 | Badge 只用 outline/secondary 两档，零挂载=outline+muted 文字，无彩色 |
| 降级/事件横幅 | bg-muted/40 + border + muted 文字，出口是链接或 ghost，永不用 destructive |
| 表格行 | 可点击行 = cursor-pointer + focus ring + aria-label；描述 truncate max-w-[280px] |
| 面板宽度 | 详情 360px / diff Sheet 520px（两个项目级固定值） |

## 12. Accessibility 立场

灰阶=天然色盲安全；文字对比 foreground/background ≈12:1、muted-foreground ≈4.6:1（AA 过线，SwiftUI 侧禁再调浅）；focus-visible 全站可见；禁用态 opacity+cursor 双标识（edge G7）；红仅为不可逆。

## 13~16. Gradients / 图像 / 字体源 / 布局系统

无渐变、无位图（纯文字+图标产品）。字体 JetBrains Mono 本地打包 → 对应 Swift 侧 SPM 引入 `JetBrainsMonoNL` 或随 App bundle。布局：NavigationSplitView 三段（侧栏×列表×详情）+ Sheet/Dialog 两型覆层 + Toast（sonner → SwiftUI 用自定义 overlay）。

## 17. Conflicts / 偏差记录

1. dark `sidebar-primary` 蓝色 ≠ 灰阶宪法 → 实现期统一为灰。
2. `@theme inline` 中 heading=mono（预设 lyra 特性）→ 保留，即项目人格。
3. usage 计数含组件库内部文件（focus-visible 47）→ 业务侧真实计数约 1/3，趋势结论不变。
